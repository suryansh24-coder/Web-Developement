# Experiment 5 — Weather App using Fetch API
1. Create a free API key at https://openweathermap.org/api.
2. Replace `YOUR_OPENWEATHERMAP_API_KEY` in `index.html`.
3. Open with Live Server and search for a city.

Uses `fetch`, `async/await`, JSON parsing and error handling. For a public production website, keep API credentials on a server rather than exposing them in browser code.
