# Web Designing Lab — 12 Experiments

Each experiment has its own folder and a short README with run instructions.

## Requirements
- Experiments 1–6 and 10–11: browser + VS Code (Live Server is convenient).
- Experiments 7–9 and 12: Node.js and npm.
- Experiment 5: a free OpenWeatherMap API key.
- Experiments 9 and 12: MongoDB connection string.

## Experiments
1. Git and GitHub Pages
2. Personal portfolio
3. JavaScript To-Do List
4. SEO and accessibility
5. Weather app using Fetch API
6. Responsive blog using Bootstrap
7. React notes SPA (CRUD)
8. Node.js + Express Book REST API
9. Authentication with Express, MongoDB and JWT
10. Static/dynamic deployment guide
11. Website performance optimization
12. MERN notes app

Use your own API keys and database credentials. Never commit `.env` files or secrets to GitHub.
